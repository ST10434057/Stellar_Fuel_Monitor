## Full description

Stellar Fuel Monitor is a mobile fleet-fuel intelligence application designed for operational monitoring and investigation. It connects to a custom REST API to present fleet performance, vehicle fuel history, trip-level analysis, alerts and reports on a native Android interface.

Key capabilities include:

- secure Google/Microsoft single sign-on with biometric verification;
- fleet dashboard and vehicle performance monitoring;
- trip investigation and historical fuel benchmarking;
- alert review and status workflows;
- offline-capable alert actions with automatic synchronisation after reconnection;
- real-time Firebase Cloud Messaging alerts;
- English, Afrikaans and isiZulu interface support;
- Evidence Vault uploads backed by cloud blob storage; and
- an investigation watchlist with priorities and operational context.

This build was prepared as an academic software-development project. Availability of fleet data and cloud services depends on the configured organisation environment.
